# Standard Onboarding Checklist (with service-line variants)

*Elevate Accounting. One checklist for the whole firm. Tick the common steps for every client; add the variant block for the service line.*

Replace the individual spreadsheets. This is the single checklist, mirrored by the tracker. Owner initials and dates go in the tracker, not here; this is the "what good looks like" reference.

## Common steps (every client)

- [ ] Engagement recorded in Xero Practice Manager and HubSpot
- [ ] Client owner assigned
- [ ] Personal welcome sent (assistant draft, owner reviewed and sent)
- [ ] Service line and variant confirmed; any exception flagged
- [ ] Document request sent from the matrix (correct set for the service line)
- [ ] Core documents received: signatory identity, entity details, authority to act, bank details
- [ ] Identity verification completed per the firm AML/KYC control (staff owned)
- [ ] Must-have set complete (see completeness rules) before booking the first meeting
- [ ] Client set up in Xero and FYI
- [ ] Engagement letter signed via Adobe Sign
- [ ] Briefing pack prepared for the first advisory meeting
- [ ] First advisory meeting held
- [ ] Warm handover to the ongoing team; client knows their point of contact

## Business advisory (add)

- [ ] Prior-year financial statements received
- [ ] Accounting software access confirmed
- [ ] Advisory goals / pre-meeting note captured
- [ ] Management accounts received (chase, non-blocking)
- [ ] Entity structure diagram received (chase, non-blocking)
- [ ] Complex structure? Partner review booked before first meeting

## Tax compliance (add)

- [ ] TFN and ATO agent linking completed
- [ ] Prior-year tax returns received
- [ ] Lodgement history confirmed
- [ ] Overdue prior-year lodgements? Partner to agree approach before proceeding

## Bookkeeping (add)

- [ ] Accounting software access confirmed
- [ ] Bank feed authority in place
- [ ] Transaction volume and reporting cadence agreed
- [ ] Chart-of-accounts preferences captured (chase, non-blocking)
- [ ] Messy or migrating file? Scoping call before committing a start date
