# Prompt, Interview note (for the file)

**Purpose.** Produce a clean, consistent interview note in the firm template for the Bullhorn record.
**Inputs.** Rough notes, role, date.

---

## Prompt

```
Turn my rough notes into a FutureHire interview note for the file. Use ONLY my
notes; mark gaps as [[CONFIRM]]. Same fairness rules as our summaries: job-
relevant evidence only, no protected attributes or proxies, no decisions.

Role: [ROLE]   Interview date: [DATE]   Stage: [STAGE]
Rough notes: <paste>

Produce:
- Overview (factual, 2-3 sentences)
- Key points discussed
- Evidence against requirements
- Follow-ups / next steps (owner + timing)

Plain, professional, concise.
```

## Guardrails
- Evidence-only; no protected attributes; no decision; flags gaps.

## Quality & fairness checks
Firm-wide checks; note is factual and file-appropriate; next steps have owners.
