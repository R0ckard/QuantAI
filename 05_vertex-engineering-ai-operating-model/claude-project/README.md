# Claude Project Configurations

A Claude Project bundles custom instructions and reference material so a whole team runs the same workflow the same way, without pasting setup each time. These files are the setup guides for the two pilots that run on Claude (proposals and bids; technical report drafting and QA). The third pilot, project status reporting, runs primarily on Copilot in-tenant, so its configuration is a Copilot usage note rather than a Claude Project (`copilot_status_reporting_setup.md`).

Each guide gives you the Project instructions to paste, the reference material to attach, and how the BD or engineering Champion keeps it current.

Files:

- `proposals_and_bids_project.md`
- `technical_report_qa_project.md`
- `copilot_status_reporting_setup.md`

All Projects live in the firm's Claude Team instance so client and commercial material stays governed. The relevant AI Champion owns each Project and reviews it each quarter with the governance forum.
